# 机器端口转发

入口为机器行的网络图标（端口转发），或机器详情中的“端口”。面板实时向 InstaBox 读取配置，不在 D1 中另存一份转发表；无需额外配置或数据库迁移。

## 操作

1. 打开机器的端口转发窗口，查看端口、名称、发布时间和公网 HTTPS 地址。若多个账号可访问这台机器，可选择操作账号；请求只使用所选账号的 Key。
2. 点击“发布端口”，填写机器中正在监听的 HTTP 服务端口和可选名称，再点击“确认发布”。留空名称时使用 `Port 端口号`。
3. 使用列表的改名按钮修改名称。改名调用平台对同一端口的发布接口，保留原地址；如需更换服务端口，发布新端口后再取消旧转发。
4. 复制地址或在新标签页访问。发布不会启动服务，也不会主动启动、恢复机器。
5. 取消转发时确认端口及名称。公网地址会失效，活跃连接会断开；机器内的服务不会被停止。

这是 HTTP 服务的 HTTPS 公网入口，不是通用 TCP/UDP、SSH 或任意目标地址转发。公网地址可被任何持有链接的人访问，面板的管理员登录不会保护端口上的服务；敏感服务应有自己的登录机制。

机器暂停或停止时配置仍保留，地址返回不可用，待机器和服务恢复后继续工作。平台未启用公网端口时显示不可用状态。面板只提供 HTTPS 链接；异常或不安全的地址不会成为可点击链接。

## 权限与限制

| 操作 | API Key 权限 |
| --- | --- |
| 查看端口 | `machines:read` |
| 发布、改名、取消转发 | `machines:write`（包含读取权限） |

每台机器最多 16 个公开端口。端口必须是 1024–65535 的整数，名称最多 100 个字符；`5901`（桌面）、`6768`（Orca）以及平台配置的 Orca 端口保留。当前面板预先校验两个固定保留端口，额外的服务端保留端口由平台拒绝。

达到上限后仍可修改已有名称或取消转发。账号停用、读取失败或刷新尚未完成时，界面禁止修改，避免使用未确认的配置。

## 结果确认与错误处理

打开窗口、切换账号、点击“刷新端口”及完成修改后都会重新读取列表；不在后台持续轮询。读取结果不会覆盖正在填写的表单或抹掉修改错误。

网络中断或上游故障可能发生在操作已经生效之后。面板保留“提交结果尚未确认”提示并重新读取列表，不自动重复发布或删除，也不把未确认请求显示为成功。请先核对列表；取消转发前会再次读取平台配置，对已重新发布、标识改变的旧条目要求重新确认。这个检查不是平台侧原子锁，若同时在其他客户端修改，请以刷新后的平台状态为准。

权限不足时按提示更换所选账号的 Key。平台限流、额度不足和服务不可用会显示中文提示；上游原始错误、凭据和浏览器 Cookie 不会被透传。

## 接口

所有面板接口都需要管理员会话；写入还校验同源 Origin、`X-Panel-Request` 和 JSON 请求体。

| 面板接口 | 平台接口 | 用途 |
| --- | --- | --- |
| `GET /api/accounts/:id/machines/:machineId/ports` | `GET /v1/machines/{id}/ports` | 返回 `{enabled, ports}` |
| `POST /api/accounts/:id/machines/:machineId/ports` | `POST /v1/machines/{id}/ports` | 提交 `{port, name}`，发布或改名 |
| `DELETE /api/accounts/:id/machines/:machineId/ports/:port` | `GET /v1/machines/{id}/ports` 后 `DELETE /v1/machines/{id}/ports/{port}` | 提交 `{confirmPort, portId}`，复核后取消转发 |

依据 2026-10-27 获取的 InstaBox OpenAPI `PublicPort`、`PublicPortList`、`PublishPortRequest` 定义。平台接口只接收固定 API 主机下的机器和端口路径，不接收用户指定的代理目标。

本地测试覆盖权限隔离、校验、改名、204 响应、失联、取消确认、恶意链接及桌面／手机操作。浏览器检查使用演示数据和模拟平台响应；真实 Cloudflare → InstaBox 链路仍需部署后验收。
